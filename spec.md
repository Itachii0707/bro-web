Technical Specification: AI-Powered Product Recommendation PWA (India Electronics & Gadgets)

1. System Overview
   Application Type: Progressive Web App (PWA) with offline caching, installable manifest, and push notifications for price drops.
   Target Market: India (INR currency, Indian e-commerce & D2C brand portals).
   Product Scope: All consumer electronics, computing, mobile devices, wearables, peripherals, components, and smart home appliances (mirroring Amazon India & Flipkart Electronics/Mobiles/Appliances taxonomies).
   Core Capabilities:

- Multi-modal AI product discovery & recommendation engine.
- Granular Amazon/Flipkart-parity parametric filtering.
- Direct product lookup & deep specification comparison (e.g., iPhone 17 Pro Max).
- Real-time, unmanipulated base price aggregation across marketplaces and official brand stores.
- Dynamic bank offer, credit card discount, and EMI calculation matrix.

2. System Architecture
   High-Level Stack:

- Frontend (PWA): Next.js (App Router) / React, TypeScript, Tailwind CSS, Workbox (Service Worker for offline state & caching), IndexedDB (local filter/comparison persistence).
- API Gateway & Orchestration: FastAPI (Python) or Node.js (NestJS) with GraphQL/REST endpoints and WebSockets/SSE for streaming AI recommendations.
- AI & Search Layer:
- LLM Orchestrator: LangGraph / LlamaIndex with function calling (intent extraction, query translation, spec reasoning).
- Vector Database: Qdrant or pgvector (semantic embeddings of product specs, reviews, and use-cases).
- Hybrid Search Engine: Elasticsearch / Meilisearch (BM25 lexical search + faceted parametric filtering).
- Data Ingestion & Scraping Pipeline:
- Distributed Playwright/Puppeteer headless browser cluster with residential Indian proxies and TLS fingerprint randomization.
- Official Affiliate/Partner APIs (Amazon Creators API, Flipkart Affiliate API) supplemented by structured DOM/JSON-LD parsers.
- Apache Kafka / RabbitMQ for ingestion event streaming; Celery/Temporal for scheduled crawls.
- Primary Storage: PostgreSQL (normalized product catalog, variants, pricing history, bank offer rules) + Redis (real-time price cache, session state).

3. Frontend Architecture & User Flows
   Page 1: Landing & Onboarding (/ - Welcome Screen)

- Purpose: Fast entry point introducing AI capabilities and immediate routing.
- Components:
- Hero Section: Value proposition + primary CTA (Start AI Recommendation) + quick-access category pills (Smartphones, Laptops, Audio, Wearables, PC Components, Smart Home).
- Global Quick-Search Bar: Instant autocomplete for direct product lookups (e.g., typing "iPhone 17 Pro Max" jumps directly to the Product Deep-Dive & Price Matrix view).
- PWA Install Prompt: Custom beforeinstallprompt banner for mobile/desktop installation.

Page 2: AI Recommendation & Discovery Workspace (/discover)

- Layout: Split-pane / responsive drawer layout combining conversational AI with deterministic faceted filtering.
- Pane A: AI Conversational & Intent Assistant
- Natural language prompt input (supports English & Hinglish queries, e.g., "Gaming laptop under 90k with RTX 4060 and good battery").
- Dynamic follow-up clarifying chips generated by LLM based on missing constraints (use-case, budget ceiling, preferred brand, portability vs. performance).
- AI-to-Filter Sync: Natural language constraints automatically populate and lock corresponding UI filters in Pane B (and vice versa).
- Pane B: Amazon & Flipkart Parity Filter Engine
- Dynamically renders category-specific facets retrieved from the schema registry:
- Global Filters: Price Range (min/max slider + buckets), Brand, Customer Rating (4 stars & up), Availability (In Stock / Pincode delivery check), Seller/Platform (Amazon, Flipkart, Brand Official Store), Discount %, Release Year.
- Smartphones/Tablets: RAM (4GB to 24GB+), Internal Storage (64GB to 1TB+), Processor/SoC (Snapdragon, Dimensity, Apple A-series), Display Type (AMOLED, LTPO, OLED), Refresh Rate (60Hz-165Hz), Battery Capacity (mAh), Charging Speed (W), 5G Bands, Rear/Front Camera MP, OIS support, IP Rating.
- Laptops & PCs: CPU Family & Generation, GPU Model & TGP (W), RAM Type (DDR4/DDR5/LPDDR5X) & Upgradability, SSD Type (Gen4/Gen5 NVMe), Display Size, Resolution, Panel Type (IPS/OLED/Mini-LED), Color Gamut (100% sRGB/DCI-P3), Weight (kg), OS.
- Audio & Wearables: Form Factor (TWS, Over-Ear, Neckband, Smartwatch, Smart Ring), ANC (dB rating), Codec Support (LDAC, aptX, LHDC), Driver Size, Battery Life, GPS/Calling support, Water Resistance.
- Peripherals, Components & Smart Home: Switch Type (Mechanical/Hall Effect), Polling Rate (Hz), DPI, Wi-Fi Standard (Wi-Fi 6E/7), Wattage, Voice Assistant Compatibility (Alexa/Google Home).
- Pane C: Ranked Recommendation Feed
- Displays top AI-matched products with match score (%), AI-generated "Why this fits you" bullet summary, key specs badge, lowest effective price, and "Compare" toggle (up to 4 products).

Page 3: Specific Product Deep-Dive & Offer Matrix (/product/[slug])

- Triggered by: Global Search Bar (e.g., "iPhone 17 Pro Max") or clicking a product card.
- Modules:

1. Variant Selector: Storage, RAM, Color, Connectivity (updates all downstream prices and offers atomically).
2. Unmanipulated Base Price Comparison Table: Side-by-side live listing price across Amazon India, Flipkart, and Official Brand D2C Stores (Apple India, Samsung Shop, Acer India Official Store, Croma, Reliance Digital).
3. Dynamic Bank & EMI Matrix: Interactive filterable table computing net effective price per payment instrument.
4. Granular Technical Specification Sheet: Categorized, normalized hardware breakdown.
5. Historical Price Chart: 30/90/180-day base price trend to detect artificial pre-sale price hikes.

6. Data Ingestion & Normalization Pipeline
   Target Sources:

- Marketplaces: Amazon India, Flipkart.
- Brand D2C Portals: Apple India, Samsung India, Acer India Official Store, OnePlus India, Xiaomi India, boAt Lifestyle, etc.
- Omnichannel Retailers (Optional secondary tier): Croma, Reliance Digital, Vijay Sales.

Unmanipulated Base Pricing Rules:

- Strict Price Separation: Ingested prices MUST separate:

1. mrp (Maximum Retail Price)
2. base_selling_price (Actual listed price before conditional coupons, exchange bonuses, or bank discounts)
3. platform_coupon (Open-to-all instant page coupons)

- Anti-Manipulation Validation:
- Reject or flag listings where base_selling_price already bakes in exchange value ("Price with Exchange").
- Track seller identity to exclude third-party scalper outliers from canonical base pricing.
- Store immutable time-series snapshots (price_snapshots table) every 15-60 minutes (high-priority SKUs) or 6 hours (long-tail SKUs).

Canonical Entity Resolution & Spec Extraction:

- SKU Deduplication: Map platform-specific IDs (ASIN on Amazon, FSN on Flipkart, Part Number / MPN on Brand sites) to a single canonical_product_id and canonical_variant_id using MPN/EAN matching + LLM-assisted attribute alignment.
- Deep Specification Extraction: Extract raw unstructured spec tables and marketing copy from product pages and normalize into structured JSONB schemas per category (Camera System, Internals & Architecture, Display & Chassis).

5. Dynamic Bank Offer & EMI Matrix Specification
   Offer Ingestion & Rule Engine:

- Parse promotional banners, API offer payloads, and checkout-preview endpoints into structured discount rules: bank_name (HDFC, ICICI, SBI, Axis, Kotak, Amex, IDFC First, HSBC), card_network (Visa, Mastercard, RuPay, Amex), instrument_type (CREDIT_CARD, DEBIT_CARD, UPI, NET_BANKING), transaction_mode (FULL_SWIPE, NO_COST_EMI, STANDARD_EMI), discount_type (FLAT, PERCENTAGE), discount_value, max_discount_cap, min_cart_value, valid_tenures (3, 6, 9, 12, 18, 24 months).

Dynamic Matrix Calculation Logic:

- Net Effective Full-Swipe Price: P_effective = P - min(CalculatedDiscount(P), max_discount_cap), evaluated only if P >= min_cart_value.
- No-Cost EMI Breakdown: Principal financed = P_effective; Monthly Installment = Principal / Tenure; explicit flags for bank processing fee and 18% GST on interest component.
- Standard EMI Breakdown: Reducing-balance interest calculation using bank-specific APR (typically 13%-16% p.a.), displaying Monthly EMI, Total Interest Paid, Processing Fee + GST, and Total Landed Cost.

UI Matrix Interaction:

- User Card Wallet Filter: Users select owned cards (stored locally in IndexedDB) to highlight the lowest landed price across all stores.
- Matrix Columns: Merchant | Base Price | Bank & Card Type | Payment Mode | Instant Discount | Monthly EMI | Hidden Fees (GST/Proc.) | Net Landed Price.

6. Core Database Schema (PostgreSQL)

- canonical_products: id (UUID PK), category_slug, brand, model_name, release_date, normalized_specs (JSONB), embedding (VECTOR(1536)), created_at.
- product_variants: id (UUID PK), product_id (FK), mpn (UNIQUE), variant_attributes (JSONB), mrp (NUMERIC).
- merchant_listings: id (UUID PK), variant_id (FK), merchant, external_sku, product_url, seller_name, is_authorized_seller, in_stock, base_selling_price, platform_coupon, last_verified_at.
- bank_offers: id (UUID PK), merchant, applicable_category, applicable_variant_id, bank_name, instrument_type, transaction_mode, discount_type, discount_value, max_discount_cap, min_cart_value, emi_tenures (INT[]), apr_percentage, processing_fee, valid_until, terms_raw.

7. API Endpoints Specification

- POST /api/v1/ai/recommend: Accepts natural language prompt + active filter state; returns streamed reasoning, updated filter parameters, and ranked canonical_products.
- GET /api/v1/filters/{category_slug}: Returns dynamic Amazon/Flipkart-parity facet definitions and value counts for a category.
- GET /api/v1/search/autocomplete: Low-latency prefix/fuzzy search returning canonical product matches.
- GET /api/v1/products/{slug}: Returns full variant tree, normalized specs, unmanipulated base prices across merchants, and 90-day price history.
- POST /api/v1/products/{variant_id}/calculate-offers: Evaluates active bank_offers against live merchant_listings for user-selected banks/tenures; returns sorted net landed price matrix.

8. PWA & Non-Functional Requirements

- Manifest & Service Worker: manifest.json with standalone display mode, adaptive icons, and Workbox caching strategies (NetworkFirst for live pricing/offers APIs, StaleWhileRevalidate for product specs/images, CacheFirst for static assets).
- Data Freshness SLA: Flagship/high-velocity SKUs refreshed every 15 minutes (with real-time on-demand scrape fallback if last_verified_at > 30 mins); standard catalog SKUs refreshed every 4 hours.
- Latency Targets: Search autocomplete < 80ms; parametric filter query < 150ms; AI first-token stream < 800ms.
